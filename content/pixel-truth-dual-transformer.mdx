Photorealism generated by modern diffusion models (Stable Diffusion XL, Midjourney, DALL-E) creates acute challenges for digital forensics and information credibility. When inspecting an uploaded image on the web, visual scrutiny is no longer sufficient to distinguish authentic photographs from neural generations.

## The Generalization Challenge

Detectors trained specifically on GAN artifacts (such as ProGAN or StyleGAN) often suffer severe degradation when evaluated against latent diffusion models. Conversely, models fine-tuned solely on diffusion outputs can miss older GAN artifacts or struggle with compression.

In our research paper, **Pixel Truth: A Dual-Transformer Ensemble for Detecting AI-Generated Images**, we approach synthetic media detection as an ensemble systems problem:

```text
RGB Image (x)
   │
   ├──> ViT Backbone (umm-maybe/AI-image-detector) ───> S_AI^(1), S_real^(1)
   │
   └──> Swin Transformer (Organika/sdxl-detector) ────> S_AI^(2), S_real^(2)
                                                             │
                                                             ▼
                                                    [ Decision Fusion ]
                                                    Majority + Average
                                                             │
                                                             ▼
                                                 Verdict + Saliency Map
```

## Mathematical Fusion Formulation

Rather than training a single opaque model, we load two independently trained checkpoints through the Hugging Face `transformers` pipeline and unify their predictions using a deterministic rule:

```text
S_AI = sum_i(s_i^AI),       S_real = sum_i(s_i^real)
A_bar_AI = S_AI / |M|,     A_bar_real = S_real / |M|
```

1. Each model outputs a label and confidence score.
2. Label vocabularies are normalized into two canonical buckets: **AI-Generated** and **Real-Image**.
3. A vote is cast if a model's score exceeds 0.5.
4. Majority vote decides the classification; ties are broken by the higher average confidence.

## Explainability via Gradient Saliency

In forensic investigations, a confidence percentage alone is rarely sufficient. Non-specialist analysts need to see *where* the model detected anomalies.

We compute an input-gradient saliency map by taking the gradient of the winning class score with respect to the input RGB pixels:

```text
M_saliency(x, y) = max_{c in {R, G, B}} | dS_c / dI(x, y, c) |
```

The resulting tensor is normalized, color-mapped with a jet colormap, and alpha-blended over the original input image. This immediately flags synthetic edge blurs, texture repetitions, or unnatural spectral inconsistencies.

## Stateless Microservice Architecture

Forensic tools handling sensitive user imagery must respect data confidentiality. PixelTruth is implemented as a stateless Flask REST API that processes images purely in-memory buffers—guaranteeing that no user uploads persist to physical disk storage.
