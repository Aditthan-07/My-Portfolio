## 🔬 Featured Research

### **Pixel Truth: Dual-Transformer Ensemble with Local Texture and Frequency Saliency for Synthetic Media Attribution**
*Aditthan J K, Dr. S. Deepa (Under Peer Review, 2026)*

* **Core Problem:** Mitigating the vulnerability of standard CNN-based deepfake detectors to adversarial post-processing (JPEG compression, Gaussian noise, motion blur).
* **Novel Architecture:** Dual-branch parallel vision transformer combining:
  1. **Spatial Stream (Swin Transformer):** Analyzes spatial RGB patches and fine edge gradients.
  2. **Frequency Stream (Frequency-Domain ViT):** Analyzes Discrete Cosine Transform (DCT) & Fast Fourier Transform (FFT) spectrogram components to detect phase inconsistencies and generative frequency artifacts.
  3. **Cross-Attention Fusion & Grad-CAM Saliency:** Yields interpretable attribution heatmaps highlighting manipulated facial boundaries and artifact clusters.
* **Empirical Benchmarks:**
  - **91.8% Attribution Accuracy** & **0.942 AUC-ROC** on FaceForensics++ and Celeb-DF v2.
  - Robust against quality factor $Q=50$ JPEG re-compression with less than 4.1% performance degradation.
* **Paper & Assets:** Interactive SVG architecture diagram modal, full markdown manuscript, and PDF preprints integrated directly into the portfolio.

## 💻 Getting Started Locally

### Prerequisites
* **Node.js**: `v18.0.0` or higher
* **npm**: `v9.0.0` or higher

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aditthan-07/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   npm run start
   ```
